# Quranic Arabic Grammar in Pashto (د عامه جزء پښتو اعراب او نحو)
Native Android application built with Kotlin, Coroutines, OkHttp, and Material Design.

## Features
- 100% offline first (assets/juz_amma_grammar.json)
- Dynamic online sync with internal storage caching (context.filesDir)
- Deep Green & White Islamic educational theme
- Word-by-word grammatical analysis in Pashto
